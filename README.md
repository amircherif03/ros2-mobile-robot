# ROS2 Autonomous Mobile Robot

> Personal Project — INSAT Tunis 2026 | Robotics & Embedded Systems

## Overview
Autonomous mobile robot built on ROS2 with full Nav2 navigation stack integration
and Gazebo simulation. Extension of the PFA cleaning robot project ported to
a production-grade robotics framework.

## Tech Stack
| Layer | Technology |
|-------|-----------|
| Framework | ROS2 Humble |
| Languages | C++17, Python 3 |
| Simulation | Gazebo |
| Navigation | Nav2 (autonomous navigation + obstacle avoidance) |
| Hardware target | Raspberry Pi 4 |
| OS | Ubuntu 22.04 / Linux |
